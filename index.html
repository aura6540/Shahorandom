♟️ Шахорандом — отдельный анализатор Stockfish

Вставь данные, скопированные из окна завершения партии в Шахорандоме. Анализатор проверяет сохранённые позиции по одной. Для каждой позиции движок предлагает лучший ход по обычным шахматным правилам; правило телепортации он не учитывает.

Ожидаю данные партии.

Если движок не запускается даже здесь, проблема не в меню основной игры: вероятно, Chrome ограничивает Blob Worker/WASM для локальных HTML-файлов. Тогда понадобится другой способ размещения движка.
